## 本地改了什么

- `SKILL.md` 为本地编写：把原文的提示词整理成“先判断需求/卡点，再选方法”的路由结构，
  补写了适用与不适用场景、执行纪律、常见失败模式和验收标准，这些内容原文没有。
- 原文按“一段说明 + 一段提示词”组织，面向人类手动复制；本地改成面向 Agent 执行，
  并按本仓库约定把长模板移入 `references/`。
- `references/prompt-templates.md` 收录三个可复制模板，其条目结构与措辞与原文提示词接近，仅做排版、标点和少量表述调整，并新增每个方法的“关键/适用场景”提示。
